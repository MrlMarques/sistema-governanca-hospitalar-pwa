# Sistema de Governança Hospitalar • Pio XII

Ecossistema Multi-PWA desenvolvido para auditoria de higienização hospitalar, controle de leitos e conformidade com os protocolos de acreditação **ONA**.

## 🚀 Arquitetura e Tecnologias
* **Frontend:** HTML5, CSS3, JavaScript Vanilla (PWA com Service Worker).
* **Backend:** Google Apps Script (API REST) integrado ao Google Sheets.
* **Hospedagem:** GitHub Pages.

## 📱 Módulos
* **Portal (`portal.html`):** Hub de navegação principal.
* **Checklist (`index.html`):** Auditoria de 32 itens (Quarto e Banheiro).
* **Dashboard (`dashboard.html`):** Indicadores e relatórios ONA.
* **PDCA (`pdca.html`):** Gestão de planos de ação.
* **Modo TV (`tv.html`):** Gestão à vista para monitores.
